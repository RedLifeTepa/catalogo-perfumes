# AuraERP v1.9.5.9 - Nombre comercial opcional

- `Nombre del negocio` puede quedar completamente vacío.
- Si el logotipo ya contiene el nombre, AuraERP no agrega texto adicional en el catálogo.
- Las páginas públicas ocultan el nombre textual cuando está vacío.
- Los formatos imprimibles muestran únicamente el logotipo cuando el nombre está vacío.
- Si posteriormente se captura un nombre, vuelve a mostrarse automáticamente.
- Se agregó una ayuda visual en Configuración explicando que el campo es opcional.
